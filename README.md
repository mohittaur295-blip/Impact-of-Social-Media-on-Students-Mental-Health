# 📊 Social Media Impact on Student Mental Health

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of the relationship between social media usage and student mental health. The analysis explores how factors such as social media usage, daily unlocks, study hours, sleep duration, physical activity, academic level, and stress level are associated with students' mental health scores.

The main objective is to clean, analyze, visualize, and extract meaningful insights from the dataset using Python and popular data analysis libraries.

## 🎯 Objectives

- Understand patterns in students' social media usage.
- Analyze the relationship between social media usage and mental health.
- Study the impact of lifestyle factors such as sleep, study hours, and physical activity.
- Compare mental health across different academic levels and stress levels.
- Identify important patterns and relationships through data visualization.
- Generate meaningful insights from the dataset using EDA.

## 🔍 Analysis Performed

### 1. Data Cleaning
- Checked dataset structure and data types.
- Identified missing values.
- Checked and handled duplicate records.
- Identified potential outliers.
- Converted columns into appropriate data types where required.

### 2. Univariate Analysis
Analyzed individual variables such as:

- Age
- Average Daily Usage Hours
- Daily Unlocks
- Study Hours
- Physical Activity Hours
- Sleep Hours Per Night
- Mental Health Score

### 3. Bivariate Analysis

Explored relationships between important variables, including:

- Social Media Usage vs Mental Health Score
- Stress Level vs Mental Health Score
- Sleep Hours vs Mental Health Score
- Study Hours vs Mental Health Score
- Physical Activity vs Mental Health Score
- Social Media Platform vs Mental Health
- Academic Level vs Mental Health

### 4. Multivariate Analysis

Analyzed multiple variables together to understand how different lifestyle and social media factors interact with student mental health.

## 📈 Visualizations

The project includes various visualizations such as:

- Histograms

- Scatter Plots

These visualizations help identify trends, distributions, relationships, and potential outliers in the dataset.
